<p>本文讲海外专线的带宽档位和选购参数。先说常见带宽有多大、独享与共享差在哪，再列参数表里容易漏掉的项，接着讲带宽和IP数量的配比、怎么把带宽测准，最后说合同里带宽条款怎么写。</p>
<h2>一、市面上常见的带宽档位</h2>
<p>单条跨境专线的带宽常见为十兆、二十兆、五十兆、一百兆、两百兆，再往上按千兆计。中小企业多用二十到一百兆，直播与多设备场景会到两百兆以上。</p>
<p>带宽是双向还是单向要说清。多数报价给的是上下行对称的独享带宽，也有只保下行、上行限速的，做上传类业务时差别很大。</p>
<p>起步不建议直接上大带宽。先按并发数和单连接占用估算，跑一段时间看峰值，再决定加不加，比一次买足更省钱。</p>
<h2>二、独享带宽与共享带宽的差别</h2>
<p>独享是把这段带宽划给你，别人用不到；共享是多人分一个池子，闲时够用，晚高峰会掉。两者的报价差通常在两三倍。</p>
<p>共享带宽的问题不在平均值，而在抖动。做实时语音、直播推流时，抖动比峰值速率更影响体验。</p>
<p>判断办法是问清保底带宽和突发上限。只写最高多少兆而不写保底的，多半是共享池。</p>
<h2>三、参数表里最容易被跳过的几项</h2>
<h3>上行与下行</h3>
<p>下行标一百兆、上行只有十兆的线路并不少见。做文件同步、直播推流，上行才是瓶颈，签之前单独确认。</p>
<p>另一项是IP的归属与类型，是机房段还是住宅段，ASN 属于哪家运营商。这一项决定了地址在目标平台眼里的样子。</p>
<h3>超量与限速</h3>
<p>超量后的处理分两种，一是限速到某个值，二是按流量加收。前者影响体验，后者影响账单，都要提前写明。</p>
<p>还有并发连接数。NAT 型线路常限制单IP的连接数，跑多标签页业务时容易先撞到这个上限，而不是带宽。</p>

<h2>四、带宽与IP数量怎么配</h2>
<p>IP 数量和带宽不是一比一的关系。十个IP共享五十兆，和两个IP各分二十五兆，是两种完全不同的用法。</p>
<p>多账号场景里，每个环境分到的带宽不需要很大，十到二十兆通常够用，关键是每条线路稳定，不要互相抢占。</p>
<p>如果所有业务跑在同一段带宽上，某个环境跑满会把其他环境拖慢。按环境做限速或分流，比单纯加带宽更有效。</p>

<h2>五、怎么把带宽测准</h2>
<p>先测空载，再测满载。空载看延迟和丢包，满载看速率能否稳定在标称值的八九成，掉到一半说明线路被共享或限速。</p>
<p>测速点要选对。用本地测速站测跨境线路没有意义，应该在落地端反向拉流，或用多线程下载大文件观察持续速率。</p>
<p>连续测三天，覆盖早晚高峰。单次测速的结果参考价值有限，峰值时段的表现才决定业务能不能稳定跑。</p>
<h2>六、合同里关于带宽的条款</h2>
<p>合同应写明带宽数值、独享或共享、上下行是否对称、超量处理方式、可用率承诺，这五项缺一项，后面都容易扯皮。</p>
<p>可用率一般写成月度百分比，注意是否扣除计划内维护时间，以及不达标时的补偿方式，有的只补天数，有的按比例退费。</p>
<h3>扩容与降配</h3>
<p>扩容通常需要提前申请，能否当天生效取决于机房是否有余量。降配往往要等到下一个计费周期，签约前问清。</p>
<h2>常见问答</h2>
<h3>跨境专线一百兆带宽够用吗？</h3>
<p>答：取决于用法。单机后台操作和多个轻量环境，二十到五十兆就够；直播推流、批量上传才需要一百兆以上。</p>
<h3>带宽和延迟是一回事吗？</h3>
<p>答：不是。带宽决定单位时间能传多少，延迟决定一来一回要多久。带宽再大，路由绕远了一样慢。</p>
<h3>共享带宽能用于长期账号运营吗？</h3>
<p>答：晚高峰抖动明显时体验不稳。若业务对连续性要求高，优先选带保底的独享线路。</p>
<h3>测速达到标称值的多少算正常？</h3>
<p>答：跨境线路在八九成属于正常范围，持续低于六成需要排查是否被限速或线路拥塞。</p>
